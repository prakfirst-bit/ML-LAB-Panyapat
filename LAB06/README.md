# LAB06: การจำแนกโรคปอดบวมจากภาพถ่ายรังสีทรวงอกด้วยโครงข่ายประสาทเทียม (Neural Network / MLP)

โปรเจกต์นี้เป็นส่วนหนึ่งของ **LAB06: Chest X-Ray Pneumonia Classification** โดยมุ่งเน้นการใช้โครงข่ายประสาทเทียมแบบ Multi-Layer Perceptron (MLP / Fully Connected Neural Network) ในการจำแนกภาพถ่ายรังสีทรวงอกออกเป็น 2 คลาส ได้แก่ **ปกติ (NORMAL)** และ **ปอดบวม (PNEUMONIA)**

---

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
LAB06/
├── classification/
│   ├── data_loader.py       # การโหลดข้อมูล การปรับขนาดภาพ และทำ Flattening/Normalization
│   ├── model.py             # การกำหนดสถาปัตยกรรมโครงข่ายประสาทเทียม (Neural Network Architecture)
│   ├── train.py             # ลูปการเทรนโมเดลและการปรับค่า Weight/Bias
│   ├── evaluate.py          # การประเมินผลโมเดล (Accuracy, Loss, Confusion Matrix)
│   ├── main.py              # สคริปต์หลักสำหรับสั่งรันโปรเซสทั้งหมด
│   └── outputs/             # โฟลเดอร์เก็บผลลัพธ์ กราฟประสิทธิภาพ และ Log การประเมินผล
├── requirements.txt         # รายการ ไลบรารีที่จำเป็นต้องติดตั้ง
└── README.md                # เอกสารอธิบายโปรเจกต์และรายงานผลการทดลอง
ญหาและข้อจำกัดที่พบในการทดลอง (Key Challenges & Issues)
จากการฝึกสอนและประเมินผลโมเดล Neural Network (MLP) พบปัญหาหลักดังนี้:

ข้อมูลมีความไม่สมดุล (Data Imbalance)

ปัญหา: จำนวนภาพถ่ายในคลาส PNEUMONIA มีปริมาณมากกว่าคลาส NORMAL อย่างมีนัยสำคัญ

ผลกระทบ: โมเดลมีความเอนเอียง (Bias) ไปทางคลาส PNEUMONIA ส่งผลให้ค่า Recall ของคลาส NORMAL ต่ำกว่าคลาสปอดบวม (ทายคลาสปกติผิดเป็นปอดบวมค่อนข้างบ่อย)

ข้อจำกัดของสถาปัตยกรรม Neural Network (MLP) กับข้อมูลภาพ

ปัญหา: โครงข่ายประสาทเทียมแบบระนาบ (Fully Connected Layer) จำเป็นต้องแปลงภาพ 2 มิติให้เป็นเวกเตอร์ 1 มิติ (Flattening) ทำให้สูญเสียความสัมพันธ์เชิงพื้นที่ (Spatial Relationships) ของพิกเซลรอบข้าง

ผลกระทบ: โมเดลจับลวดลายหรือขอบเขตของถุงลมปอดได้ไม่ดีเท่าที่ควร ทำให้ค่า Accuracy สิ้นสุดประเมินอยู่ที่ประมาณ ~86.5%

การเกิด Overfitting

ปัญหา: เนื่องจาก Fully Connected Layer มีจำนวนพารามิเตอร์ (Weight) สูงมาก ทำให้โมเดลจดจำข้อมูลในชุดฝึกสอน (Training Set) ได้ดีเกินไป

ผลกระทบ: กราฟความถูกต้องในชุดเทรนสูงถึง ~95% แต่ค่า Accuracy บนชุดทดสอบจอดอยู่ที่ ~86.5% เกิดช่องว่าง (Generalization Gap) ชัดเจน
